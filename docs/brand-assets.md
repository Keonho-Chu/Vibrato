# Brand assets

Vibrato follows the LIG System corporate identity (see [design-system.md](design-system.md)). The LIG System logotype files below are reproduced from the CI guide's logo data without modification other than scaling and cropping to the guide's clear-space margin; never recolour, outline, tilt, or redraw them. Character and hero images remain in `assets/` for README and documentation surfaces.

| Asset | Purpose |
| --- | --- |
| [`assets/lig-system.png`](../assets/lig-system.png) | LIG System logotype, LIG Innovative Blue, for white/light grounds (README header on light GitHub). |
| [`assets/lig-system-w.png`](../assets/lig-system-w.png) | LIG System logotype, white, for LIG-blue or dark grounds (README header on dark GitHub, HTML export header). |
| [`assets/logo-vertical.png`](../assets/logo-vertical.png) | Vertical README/docs logo lockup for Vibrato. |
| [`assets/hero.png`](../assets/hero.png) | Wide README/docs hero image for Vibrato. |
| [`assets/character.png`](../assets/character.png) | Standalone Vibrato character mascot. |
| [`assets/rlm.png`](../assets/rlm.png) | Feature card for the `autoresearch` research/REPL mode (scientist mascot). |
| [`assets/computer-use.png`](../assets/computer-use.png) | Feature card for the `computer-use` desktop-control surface (operator mascot). |
| [`assets/telegram-mobile-hero.png`](../assets/telegram-mobile-hero.png) | Feature card for the Telegram/mobile notifications flow. |
| [`assets/tool-image-fixture.webp`](../assets/tool-image-fixture.webp) | Minimal WebP fixture for terminal image rendering tests. Not a product brand asset. |

The old legacy demo artwork has been removed from the active asset set; new public surfaces should reference the Vibrato assets above.
